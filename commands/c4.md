# C4 — 코드베이스 → 아키텍처 문서

`/arch-doc`의 별칭. C4 모델(Context → Container → Component → Code) 기반
아키텍처 문서를 생성한다.

`~/.claude/commands/arch-doc.md`의 절차를 그대로 따른다. `$ARGUMENTS`를 그대로 전달.

핵심만 다시:

1. **모드 판단** — 기존 코드 문서화면 `mode-document-code.md` 로드
2. **확인 3개** — 스코프 / 레벨(Context+Container 기본) / 출력 위치(`docs/architecture/`)
3. **스캔** — 50파일 초과면 `Agent` `subagent_type: Explore`로 위임
4. **발견 내용 먼저 제시** 후 확인받기
5. **초안 → 반복 → 승인 후 저장**

지킬 것: 추론은 *Assumptions* 섹션으로 분리, 빈칸을 상상으로 채우지 않기,
승인 전 최종 파일 쓰지 않기, `.env` 읽지 않기(`.env.example`만).

스킬 전문: `~/.claude/skills/c4-model/SKILL.md`
